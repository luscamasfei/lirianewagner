# Liriane Wagner · Architecture and Interiors

Digital portfolio of **architect Liriane Wagner**, based in **Passo Fundo, Rio Grande do Sul, Brazil**.

**Live site:** [lirianewagner.com.br](https://lirianewagner.com.br) (in Portuguese)

The site presents the architect's architecture and interior design projects and leads visitors to request a quote through WhatsApp, the main contact channel for professionals in Brazil. It replaces a simple link-in-bio page with a portfolio that feels like an architecture studio's: a full-screen cinematic opening, editorial typography and the projects front and center, all built around the architect's official logo.

## Features

- **Home page:** full-screen opening, about the architect, selected projects, services, work process and contact.
- **One page per project,** with a full-screen cover, project data sheet, concept, challenge, solutions, materials, gallery and technical drawings. Each project has its own URL for sharing and search indexing.
- **WhatsApp contact** with a pre-filled message for each context. An optional pre-quote form turns the answers into a single message; no data is stored on the site.
- **Image lightbox** with keyboard and swipe navigation.
- **Honest project labels:** each project states whether it is professional or academic work.
- **Accessibility:** keyboard navigation, visible focus, reviewed contrast and support for the reduced-motion preference.
- **Performance:** responsive WebP and JPEG images, lazy loading and self-hosted fonts.
- **SEO:** per-page titles and descriptions, structured data (schema.org), sitemap, robots.txt and social sharing images.

## How it works

A static site with **no framework and no npm dependencies**. Node.js scripts generate the HTML from data files:

```
src/data/site.mjs        contact details, social links, WhatsApp messages and navigation
src/data/projects.mjs    projects: copy, data sheet, gallery and drawings
src/data/services.mjs    services and work process steps
src/data/images.json     image dimensions (generated by scripts/images.mjs)
src/templates/           layout, home page and project page
src/assets/              CSS, JavaScript, fonts, logo and favicon
src/img/                 project images in several sizes
src/worker.js            redirects (www and http → https) on Cloudflare
scripts/build.mjs        builds the site into dist/, with sitemap and robots.txt
scripts/check.mjs        checks links, images, alt text and WhatsApp links
scripts/images.mjs       crops the images from the original files
scripts/serve.mjs        local server to preview the site
```

## Running locally

Requires **Node.js 18 or later**.

```bash
npm run dev      # builds the site and serves it at http://localhost:4173
npm run check    # builds the site and runs the checks
```

To use another port: `PORT=4391 npm run dev`.

The processed images are already in `src/img/`. `npm run images` is only needed to create new crops: it requires [libvips](https://www.libvips.org/) and the high-resolution originals, which are not in the repository.

## Deployment

The site is hosted on **Cloudflare** (Workers Static Assets) under the `lirianewagner.com.br` domain.

```bash
npm run deploy   # builds, runs the checks and publishes (wrangler deploy)
```

The domain and the published folder are set in `wrangler.toml`. `vercel.json` keeps the old review URL (`lirianewagner.vercel.app`) redirecting to the final domain.

For a build without the domain, for example on a test host, run `SITE_URL= npm run build`. This omits the sitemap and canonical URLs.

## Adding a project

1. Add the image crops to `CROPS` in `scripts/images.mjs` and run `npm run images`.
2. Add the project to `src/data/projects.mjs`. The `cover` field sets the card image on the home page and `hero` sets the cover of the project page.
3. Run `npm run check`. The project shows up on the home page automatically (professional work before academic work), with its own page and sitemap entry.
